## Methodological audit

- Popularity ranks by training interaction count; deterministic movie-ID
  tie-breaking is preserved. The bias model is described separately.
- Formulation A penalizes entities per interaction and formulation B penalizes
  distinct entities once per batch. The paper's gradients and matched-lambda
  interpretation are consistent with the implementation.
- Validation selects configurations and alpha. Test is used only once for each
  frozen final configuration.
- Ranking uses the full eligible catalogue, excludes training-rated movies,
  uses rating >= 4 relevance, macro-averages users, and excludes
  zero-relevant users only from Recall/NDCG.
- The chronological split is explicitly distinguished from a global timepoint
  cutoff. Unrated movies are described as unjudged, not confirmed negatives.
- Bootstrap intervals resample users 1,000 times with seed 42. They quantify
  user-level uncertainty, not training-seed variability.
- NDCG-selected variants remain labelled post-hoc because they were added
  after initial standalone test results had been observed.
