What each method does (paper methods)

Regularized bias baseline

Predicts the training mean plus user and movie rating biases. It captures general rating tendencies, but has no user–movie interaction factors.

MF A · interaction-weighted regularization

Biased matrix factorization: a user and movie each have latent vectors. In each mini-batch, an entity’s L2 penalty is applied once per rating interaction, so frequent entities receive more penalty. The saved setting used 50 factors, λ=0.05, and epoch 22.

MF B · entity-level regularization

Uses the same biased factorization and training objective, but applies each user/movie penalty once per mini-batch, not once per interaction. The RMSE-selected saved setting used 50 factors, λ=0.1, and epoch 11. Popularity is stronger on full-catalogue test NDCG; the A/B gap cannot be attributed to regularization alone.

Genre profile

Builds a multi-hot genre profile from training ratings only, weighting each movie by its rating minus the training mean; ranks candidates by cosine similarity.

Hybrid · validation-selected

Standardizes MF B and genre scores per user across eligible movies, then combines them with weight α. Validation selected α=1.0 chronologically and α=0.8 on the random split; each frozen hybrid was then evaluated once on test.

Model scores are on different scales (rating, cosine similarity, or z-score); compare rankings, not the raw score magnitudes across methods.

04 / SPLIT SENSITIVITY

The split changes the question.

Chronological evaluation approximates future recommendations. Random holdout can train on later ratings, so its higher scores are not a fair “improvement” over the chronological result.

A

Chronological

Train on earlier ratings, evaluate on later ratings. This is the primary, future-oriented protocol.

B

Random per-user

Shuffle each user’s rows into 80/10/10. Training includes later timestamps for nearly every user, giving a different and usually easier information setting.

C

Read scores in context

Compare the two rows above as different evaluation settings, not as evidence that random splitting is better for deployment.

HOW TO READ THE RESULTS

Scoring: MF predicts a clipped 1–5 rating; Genre uses cosine similarity to a training-only, mean-centered genre profile; the hybrid combines per-user standardized MF B and genre scores.

Evaluation: candidates exclude training-rated movies. A held-out rating ≥4 is relevant. Unrated recommendations are unknown—not confirmed negatives. The hybrid has no test metrics.

Reproducibility: results come from the locked chronological split and a separate random split (seed 42). Data and model files are precomputed; this static site does not retrain.
